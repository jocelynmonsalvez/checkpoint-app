# CHECKPOINT

Aplicación web para gestión y control de avance de obras de construcción.

## Base maestra
Este repositorio se ha inicializado para trabajar sobre **Checkpoint funcional v12**, preservando la funcionalidad acumulada antes de continuar con nuevas modificaciones.

La publicación web se realizará desde la rama `main`.

> Durante el desarrollo se utilizarán datos demostrativos. No introducir datos sensibles o reales de trabajadores, contratistas o clientes hasta implementar autenticación y almacenamiento adecuados.
